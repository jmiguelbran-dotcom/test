# Analizador de Logs con Criterio Humano (AI for Devs)

Solución desarrollada para la **Semana 3** del bootcamp **AI for Devs Jr. (KODIGO)**.  
El proyecto demuestra el uso de Inteligencia Artificial como asistente de desarrollo bajo estricta supervisión técnica y toma de decisiones humana (*Human-in-the-Loop*).

## Requisitos
- Python 3.8 o superior (no requiere librerías externas adicionales).

## Ejecución del Script
Ejecuta el script desde tu terminal interactiva:

```bash
python log_analyzer.py
